# Org Design Implications

If this works, "contributor to the shared insight hub" becomes part of how PM/analyst/research/design roles are defined, not just a tool they use. That's a bigger ask than a repo — worth being explicit about if it comes up.

Related open structural question: centralized vs. embedded vs. some hybrid team shape, and whether that choice changes once a shared insight repo removes some of the reason embedding existed in the first place (proximity to context that used to live only in one person's head).
